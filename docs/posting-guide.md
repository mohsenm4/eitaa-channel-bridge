# راهنمای نگارش پست‌ها برای کانال ایتای معراج

> این راهنما برای ادمین‌های کانال [@Merajyan](https://eitaa.com/Merajyan) نوشته شده. هدفش اینه که پست‌های کانال **خودکار** روی سایت موسسه منتشر بشن و **هرکدوم توی جای درست** نشون داده بشن (اطلاعیه‌ها بره توی اطلاعیه‌ها، گزارش‌ها بره گالری، و …).
>
> برای ادمین فقط **یک کار اضافه** وجود داره: گذاشتن یه **هشتگ دسته‌بندی** در ابتدای پست. بقیه چیزها مثل قبل آزاده.

---

## ۱) قانون اصلی — فقط یه هشتگ

هر پست رو با **یکی** از این هشتگ‌ها شروع کنید (یا بذارید خط اول بعد از سلام/بسم‌الله):

| هشتگ | کِی استفاده کنیم | کجای سایت می‌ره |
|---|---|---|
| `#گزارش_تصویری` | گزارش هفتگی برنامه‌ها با عکس | گالری / گزارش‌ها |
| `#اطلاعیه` | اعلام جلسه، رویداد، تغییر زمان | اطلاعیه‌ها |
| `#مناسبت` | عید، مناسبت مذهبی، تبریک | اخبار |
| `#کمک_مالی` | درخواست کمک، شماره کارت | حمایت |
| `#خبر` | خبر عمومی موسسه | اخبار |
| `#معرفی` | معرفی کادر، خدمات، فضای موسسه | درباره ما |
| `#پاسخ` | پاسخ به سوال متداول | سوالات متداول |

**اگه هیچ هشتگی نذارید**، پست توی دسته‌ی پیش‌فرض «اخبار عمومی» سایت می‌ره. گم نمی‌شه ولی توی جای درستش هم نمی‌ره. **توصیه‌ی اکید: هشتگ بذارید.**

---

## ۲) سه نشانگر اختیاری (پست شما رو روی سایت قشنگ‌تر می‌کنه)

این‌ها **اختیاری** هستن. اگه نذارید، پست بازم منتشر می‌شه. اگه بذارید، سایت ازشون استفاده می‌کنه:

| نشانگر | کاربرد | مثال |
|---|---|---|
| `🔻 ...` | **عنوان پست روی سایت** | `🔻 برنامه هفتگی فروردین` |
| `🟩 ...` | **زیرعنوان / موضوع** | `🟩 خلاقیت \| بازی` |
| `🗓 ...` | **تاریخ رویداد** | `🗓 جمعه ۱۴ فروردین ۱۴۰۵` |

اگه `🔻` نذارید، سایت **خط اول پست** رو به عنوان عنوان استفاده می‌کنه (تا ۸۰ کاراکتر).

---

## ۳) هشتگ‌های خاص — وقتی نمی‌خواید روی سایت بره

| هشتگ | اثر |
|---|---|
| `#خصوصی` | این پست **روی سایت منتشر نمی‌شه** (فقط روی کانال می‌مونه). برای پست‌های داخلی یا تستی. |
| `#نمایش_نده` | همون اثر بالا. |

---

## ۴) مثال‌های کامل

### مثال ۱: گزارش تصویری (همون قالب فعلی شما — عالیه!)

```
#گزارش_تصویری

🔻 برنامه هفتگی
🟩 خلاقیت | بازی

🗓 جمعه ۱۴ فروردین ۱۴۰۵

[۲–۴ عکس از برنامه]

#موسسه_فرهنگی_مذهبی_معراج #گزارش
🆔 @Merajyan
```

### مثال ۲: اطلاعیه جلسه

```
#اطلاعیه

🔻 جلسه ویژه مادران معراجی
🗓 جمعه ۱۸ اردیبهشت ۱۴۰۵، ساعت ۱۵:۳۰ تا ۱۷

سلام بر مادران محترم معراجی 🤝

به استحضار می‌رساند جلسه‌ای ویژه مادران معراجی در روز جمعه...

🆔 @Merajyan
```

### مثال ۳: مناسبت + کمک مالی

اگه پست **هم مناسبتیه هم درخواست کمکه**، می‌تونید **دو هشتگ** بذارید. اولی برای دسته‌بندی سایت استفاده می‌شه:

```
#مناسبت #کمک_مالی

🔻 عید سعید غدیر خم
🗓 ۲۶ خرداد ۱۴۰۵

بسم الله الرحمن الرحیم

«الْیَوْمَ أَکْمَلْتُ لَکُمْ دینَکُمْ»
فرارسیدن عید سعید غدیر خم...

💳 شماره کارت:
6062-5610-0843-2638
به نام: محمدظاهر خاوری
```

---

## ۵) چی‌ها هنوز آزاده

برای کم کردن دردسر، این‌ها هیچ قانونی ندارن — هرجور دوست دارید بنویسید:

- متن پست (طول، لحن، ایموجی، سبک)
- تعداد و چینش عکس‌ها
- استفاده از هشتگ‌های اضافی (مثل `#معراج`، `#گزارش`، …)
- فوتر پست (لینک کانال، آی‌دی)

---

## ۶) خلاصه

**فقط یادتون باشه:**
1. ✅ یه هشتگ دسته‌بندی از لیست بالا بذارید
2. (اختیاری) `🔻` برای عنوان، `🗓` برای تاریخ
3. اگه نمی‌خواید روی سایت بره → `#خصوصی`

همین. بقیه‌ش کار ماست.

## پیوست: نقشه‌ی فعلی پست‌های کانال

این که الان توی کانال هست رو با قالب جدید تطبیق دادیم:

| پست | الان چی داره | بعد از قالب |
|---|---|---|
| `#گزارش_تصویری` گزارش هفتگی | ✅ کامل (فقط هشتگ‌ها بره بالا) | بدون تغییر اساسی |
| اطلاعیه جلسه مادران | ❌ هشتگ نداره | `#اطلاعیه` بالای پست + `🔻 جلسه ویژه مادران` |
| عید غدیر + کمک مالی | ❌ هشتگ نداره | `#مناسبت #کمک_مالی` بالای پست |
